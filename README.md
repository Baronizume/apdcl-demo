# apdcl-demo
APDCL Demo is a simulated platform showcasing Assam Power Distribution Company Limited's online services, including bill viewing, payment demos, consumption tracking, and account management. Designed for testing and demonstration purposes only, it replicates the look and feel of APDCL's official portal without processing real transactions.
# APDCL Demo

A demo web application simulating core customer-facing services of **APDCL (Assam Power Distribution Company Limited)**, built to showcase how an electricity utility's digital portal could work end-to-end.

## Features

- ⚡ **Bill Payment** — View and pay electricity bills through a simulated payment flow
- 📢 **Outage & Complaint Reporting** — Report power outages or service issues and track complaint status
- 👤 **Customer Account Portal** — Manage account details, view consumption history, and access past bills

## About

This project is a demonstration/prototype and is not affiliated with or endorsed by APDCL. It's intended to explore UI/UX patterns and workflows common to utility service portals.
